# Question 1: Threat Cluster Identification

## Question

What name does Red Canary use for the threat cluster associated with the SHA256 hash in `hash.txt`? Submit the name used in its technical analysis, without adding a malware-type suffix.

## Finding

**Yellow Cockatoo**

## Investigation Methodology

1. Located the SHA256 hash contained in the provided `hash.txt` file.
2. Copied the SHA256 hash and searched for it using Google.
3. Reviewed the search results and identified a Red Canary technical analysis associated with the hash.
4. Examined the threat intelligence information to identify the threat cluster name.

## Evidence

Red Canary identifies the threat cluster associated with the SHA256 hash as **Yellow Cockatoo**.
